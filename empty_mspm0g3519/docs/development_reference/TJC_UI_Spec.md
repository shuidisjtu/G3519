# TJC 串口屏最小验证工程

> 目标：用 2 页工程掌握 TJC 屏全部核心交互技能，为比赛快速搭建 UI 打基础。
> 工程路径：`empty_mspm0g3519/TJC4827X543_011/TJC4827X543.HMI`
> 屏幕：480×272，编码 GB2312

---

## 第一步：清理出厂工程

1. 用 USART HMI 打开 `TJC4827X543.HMI`
2. 右侧页面列表中，**逐个右键删除**所有出厂页面（star, null, main, main2...）
3. 删完后页面列表应为空

## 第二步：配置字库

1. 工具栏 → **字库** → 生成字库
2. 创建 **fs0**：选 ASCII，字号 **16×32**（大号数值显示用），生成并添加
3. 创建 **fs1**：选 ASCII，字号 **8×16**（常规标签用），生成并添加

> 字库文件会自动保存在工程目录中。若字库工具入口不同版本位置有差异，在菜单栏/工具栏中查找"字库生成器"或"Font"。

## 第三步：修改 Program.s

1. 左下角点击 **Program.s**
2. 替换内容为：

```
int sys0=0,sys1=0,sys2=0
bauds=9600
printh 00 00 00 ff ff ff 88 ff ff ff
page 0
```

> `bauds=9600` 确保首次联调用低波特率，通信稳定后改 `115200`。

## 第七步：SSCOM 验证（5 项核心技能）

下载完成后，用 USB-TTL 连接屏幕，打开 SSCOM，设置 **9600, 8N1**。
勾选 **HEX 显示**（方便看返回帧），发送模式用**文本发送**。

> 提示：SSCOM 文本模式下 `\xff` 会自动转为 0xFF 字节。

### 验证 1：按钮事件接收

**操作**：触摸屏幕上的 "Test Wave" 按钮

**预期**：SSCOM 收到 `65 00 01 01 FF FF FF`

| 字节 | 含义 |
|------|------|
| 65 | 控件事件帧头 |
| 00 | page_id = 0 |
| 01 | component_id = b0 的 ID |
| 01 | event = 按下 |
| FF FF FF | 帧尾 |

> 同时屏幕会跳转到 Page 1（因为 b0 的按下事件写了 `page 1`）。
> component_id 取决于控件在页面中的实际 ID，可能不是 01，以实际收到的为准。

### 验证 2：页面跳转

**SSCOM 发送**（文本模式）：
```
page 1\xff\xff\xff
```

**预期**：屏幕跳转到 Test Page

再发送：
```
page 0\xff\xff\xff
```

**预期**：屏幕返回菜单页

### 验证 3：更新数字框

先跳转到 Page 1，然后发送：
```
n0.val=1234\xff\xff\xff
```

**预期**：数字框显示 `1234`

再发送：
```
n0.val=9999\xff\xff\xff
```

**预期**：数字框显示 `9999`

### 验证 4：更新文本框

**SSCOM 发送**：
```
t0.txt="Hello"\xff\xff\xff
```

**预期**：文本框显示 `Hello`

再发送：
```
t0.txt="VIN1 OK"\xff\xff\xff
```

**预期**：文本框显示 `VIN1 OK`

### 验证 5：波形批量透传 (addt)

这是最关键的技能，分 3 步操作：

**第 1 步 — 发送透传请求**（文本模式）：
```
addt s0.id,0,10\xff\xff\xff
```

> 先用 10 点测试，成功后再加大。

**第 2 步 — 等待就绪信号**：

SSCOM HEX 显示中应收到 `FE FF FF FF`（透传就绪）。

**第 3 步 — 发送纯二进制数据**：

切换到 **HEX 发送模式**，发送 10 字节（不加 FF FF FF 结尾！）：
```
14 28 3C 50 64 78 8C A0 B4 C8
```

> 这 10 字节换算为十进制是 20,40,60,80,100,120,140,160,180,200，应在曲线上画出一段上升斜线。

**预期**：
- 收到 `FD FF FF FF`（透传完成）
- 曲线控件上出现一段上升斜线

> 注意：透传数据期间**不加** `FF FF FF` 结尾，发完 10 字节后屏自动结束。

## 验证完成后

5 项验证全部通过后，你已掌握：

| 技能 | 对应验证 | 比赛用途 |
|------|---------|---------|
| 按钮事件 → MCU | 验证 1 | 触摸按钮触发功能切换 |
| MCU → 页面跳转 | 验证 2 | 进入/退出各功能页面 |
| MCU → 更新数值 | 验证 3 | 显示 Vpp、频率、阻抗等测量值 |
| MCU → 更新文本 | 验证 4 | 显示通道名、状态、单位等 |
| MCU → 批量波形 | 验证 5 | 示波器/FFT/扫频的波形曲线 |

比赛时根据实际题目需求，用这 5 个技能快速搭建所需页面即可。
正式工程 `bauds` 改为 `115200`，MCU 端开发 `tsp_tjc.c/.h` 驱动即可对接。
