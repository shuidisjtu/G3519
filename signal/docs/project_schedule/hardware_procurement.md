## 一、平台选型说明

### 1.1 为什么选 FRDM-MCXN947

赛题核心需求是对 10kHz~500kHz 周期信号进行高精度采样与 FFT 分析。原 MSPM0G3519 平台的 ADC（12-bit 轮询 ~204kSPS）和 FFT（256 点）远不能满足要求。FRDM-MCXN947 的硬件规格**从根本上消除了信号链瓶颈**：

| 关键指标 | 赛题需求 | MSPM0G3519 | **FRDM-MCXN947** |
|---------|---------|-----------|-------------------|
| ADC 分辨率 | 幅值误差 ≤5mV | 12-bit（LSB=0.8mV） | **16-bit（LSB=0.05mV）** |
| ADC 采样率 | ≥1 MSPS（Nyquist 500kHz） | ~204 kSPS（轮询） | **2 MSPS（16-bit）/ 3.15 MSPS（12-bit）** |
| FFT 硬件加速 | 500Hz 分辨率，2 秒内完成 | 无（纯软件 CMSIS-DSP） | **PowerQuad 硬件 FFT 引擎** |
| DAC | VGA 增益控制 | 无（需外部 XD5615） | **内置 14-bit DAC @ 5 MSPS** |
| 片内运放 | ADC 前端缓冲 | 无 | **3 路可编程增益 OPAMP** |
| CPU | FFT 运算 + UI | Cortex-M0+ 80MHz 单核 | **Dual Cortex-M33 150MHz** |
| SRAM | FFT buffer（4096点×16bit） | 256 KB | **320 KB + 32 KB ECC** |
| Flash | 程序存储 | 512 KB | **2 MB** |

## 八、关键决策点汇总

### ~~决策 1：竞赛合规性~~ ✅ 已确认

赛题对微处理器最小系统板无限制，FRDM-MCXN947 合规。

### 决策 2：VGA 前端方案

| 对比项 | AD603 | AD8367（推荐） |
|--------|-------|--------|
| 带宽 | 90 MHz | 500 MHz |
| 供电 | **±5V（需 DC-DC）** | **单电源 3.3~5V** |
| 增益控制 | DAC 电压，线性 dB | DAC 或 AGC 电容 |
| 增益范围 | -11 ~ +31 dB | -2.5 ~ +42.5 dB |
| 输入阻抗 | 100Ω（接近 50Ω） | 200Ω |
| 精度标定 | 易（线性 dB） | 中（需实测曲线） |
| 额外硬件 | ±5V DC-DC | **无** |
| 系统复杂度 | 高 | **低** |

**建议**：**优先 AD8367**。单电源、电路简单、带宽裕量大。增益用 MCX N947 内置 14-bit DAC 精确控制（VGAIN 0~1V），无需外部 DAC 模块。

### 决策 3：PowerQuad vs 软件 FFT

| 方案 | FFT 点数 | 速度 | 适用场景 |
|------|---------|------|---------|
| PowerQuad 硬件 FFT | 最大 512 点（已验证） | 极快 | 实时预览、快速粗测 |
| CMSIS-DSP 软件 FFT | 2048/4096 点 | 快（150MHz M33） | 高分辨率精确测量 |
| 混合方案（推荐） | 先 PowerQuad 粗测，再 CMSIS-DSP 精测 | 综合最优 | 2 秒时限内完成 |

500Hz 分辨率需要 fs/N = 500 → 2 MSPS / 4096 = 488Hz ≈ 500Hz，需要 **4096 点 FFT**。PowerQuad 不够，但 150MHz Cortex-M33 运行 CMSIS-DSP `arm_cfft_q15` 4096 点估计 <10ms，完全满足 2 秒时限。
