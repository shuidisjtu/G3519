## 三、模拟前端设计（自制PCB，核心难点）

### 3.1 信号链

```
BNC(50Ω) ─→ C1(隔直, 100nF) ─→ Rterm(50Ω) ─→ AD620(PGA) ─→ 
  Sallen-Key LPF(5阶, fc=600kHz) ─→ DC偏置(1.65V) ─→ ADC输入
```

### 3.2 各级参数

| 级 | 器件/拓扑 | 关键参数 | 说明 |
|----|-----------|----------|------|
| **输入接口** | BNC母座 (PCB焊接) | 50Ω特性阻抗 | 赛题硬性要求 |
| **AC耦合** | 100nF C0G电容 | f_L ≈ 3.2Hz (含50Ω端接) | 隔直流，通交流 |
| **端接电阻** | 50Ω ±1% | 与信号源阻抗匹配 | 防反射 |
| **PGA** | AD620 (现有) | BW=1MHz@G=1, BW=120kHz@G=10 | ⚠️ Part 2/3需G=1~2 |
| **抗混叠LPF** | 5阶Sallen-Key Butterworth | fc≈600kHz, 1MHz处-30dB | **Part 3关键** |
| **LPF运放** | AD8051/AD8065 | GBW≥100MHz, SR≥100V/μs | 必须在500kHz无衰减 |
| **DC偏置** | 电阻分压 + 缓冲器 | Vref=1.65V (3.3V/2) | 将±信号抬升到0~3.3V |

### 3.3 抗混叠滤波器设计（Part 3 核心）

```
目标：用硬件滤除≥1MHz的uJ干扰，防止ADC混叠

拓扑：5阶 Sallen-Key Butterworth 低通
截止频率：fc = 600kHz
阻带衰减：1MHz 处 > 30dB

200mVpp的uJ @1MHz → 经过30dB衰减 → ∼6mVpp (已接近噪声floor)
再加上数字FIR的补充抑制 → 满足5mV精度要求

备选：7阶椭圆滤波器（过渡带更陡，但元件多、调试难）
```

### 3.4 PGA增益策略

| 场景 | 输入范围 | AD620增益 | ADC输入范围 | 备注 |
|------|----------|-----------|-------------|------|
| Part 1 (ua) | 100~250mVpp | G=5~10 | 500mV~2.5Vpp | 安全范围内 |
| Part 2/3 (ub) | 50~250mVpp | G=1~5 | 50mV~1.25Vpp | 小信号需低噪声 |

> ⚠️ AD620 GBW限制：G=10时BW仅~120kHz，无法用于200kHz+。对于Part 1高频部分和Part 2/3，建议G≤2，靠12-bit ADC的0.8mV分辨率直接采样。或换宽带PGA如AD8250(BW=12MHz@G=10)。

## 四、MCXN947 固件架构

### 4.1 外设配置

| 外设 | 用途 | 配置 |
|------|------|------|
| **ADC0** | 信号采样 | 12-bit模式, 2MSPS, 单端, 硬件触发 |
| **CTimer** | 采样时钟 | 匹配2MSPS: period=150M/2M=75 ticks |
| **eDMA CH0** | ADC→BufferA | 乒乓模式主通道, 512次传输后中断+自动切换 |
| **eDMA CH1** | ADC→BufferB | 乒乓模式副通道 |
| **PowerQuad** | FIR+FFT | FIR: 64阶LPF, FFT: 512点CFFT |
| **LPUART** | TJC屏通信 | 115200-8N1, TX+DMA |
| **GPIO** | 按键+编码器 | 模式切换(ua/ub/ub+uJ) |

### 4.2 乒乓缓冲 + 处理流水线

```
时间轴 →

DMA:   [===BufA=512点===][===BufB=512点===][===BufA=512点===][===BufB...
           ↑ BufA满中断        ↑ BufB满中断        ↑ BufA满中断
           
CPU+PQ:      [处理BufA━━━━━━━━━━━━━━━][处理BufB━━━━━━━━━━━━━━━][处理BufA...
              ├─ FIR (PQ)   10μs        (并行运行，不阻塞ADC)
              ├─ RMS (CPU)  2μs
              ├─ FFT (PQ)   15μs
              ├─ 峰值检测   5μs
              └─ 更新显示   异步UART
              
关键：256μs填充时间 >> 32μs处理时间 → CPU/PQ负载仅 ~12.5%
```

### 4.3 PowerQuad 处理流程

```c
// === 每个Buffer的处理流程 ===

// 1. FIR低通滤波 (PowerQuad硬件)
//    64阶, fc=0.5*Fs/2=500kHz (相对于2MSPS)
//    FIR系数预存放在PowerQuad私有RAM (0xE0001000)
pq_fir_fast(buf_raw, buf_filtered, 512, fir_coeff_q31, 64);

// 2. 时域真有效值计算 (CPU, 又快又简单)
uint32_t sum_sq = 0;
for (int i = 0; i < 512; i++) {
    int16_t ac = buf_raw[i] - dc_offset;
    sum_sq += ac * ac;
}
float rms_mv = sqrtf(sum_sq / 512.0f) * ADC_LSB_MV;

// 3. Vpp计算 (从原始buffer)
uint16_t vmax, vmin;
find_minmax(buf_raw, 512, &vmax, &vmin);
uint16_t vpp_mv = (vmax - vmin) * ADC_LSB_MV;

// 4. FFT (PowerQuad硬件, 512点CFFT)
//    输入：FIR滤波后的数据，转为Q31定点
pq_cfft_512(buf_filtered, buf_fft_out);

// 5. 频谱峰值检测 (CPU, 搜索基波+谐波)
//    抛物线插值提高频率精度到 <500Hz
fft_find_peaks(buf_fft_out, 256, &fundamental, harmonics, 3);
```

### 4.4 频率分辨率 500Hz 的达成策略

```
直接FFT:  df = 2MSPS / 512 = 3.9kHz  ← 不够！！

解决方案（三管齐下）：

① 抛物线插值（已有验证代码，tsp_fft.c）
   true_bin = peak_bin + 0.5*(alpha - gamma)/(alpha - 2*beta + gamma)
   精度可达 df/20 ≈ 200Hz ✅

② 如果需要更大FFT（可选备选方案）：
   PowerQuad Cooley-Tukey分解 → 1024点
   df = 2MSPS/1024 ≈ 1.95kHz + 插值 ≈ 100Hz ✅

③ 过零法辅助测频（时域验证）：
   512点@2MSPS = 256μs，≥10kHz时至少2.5个周期
   过零法测周期 → 精度远超1kHz

最终策略：过零法测f1（精度高）+ FFT插值测量谐波频率
```

## 六、关键参数计算

### 6.1 采样率与精度的可行性

```
ADC: 12-bit, Vref=3.3V
LSB = 3.3V/4096 ≈ 0.806mV

输入信号: 50~250mVpp
最差情况(50mVpp, G=1):  50/0.806 ≈ 62 LSBs — 可检测但噪声敏感
最好情况(250mVpp, G=5): 1250/0.806 ≈ 1550 LSBs — 充裕

5mV精度要求: 5/0.806 ≈ 6.2 LSBs
通过512点平均(√512≈22.6倍SNR改善) → 等效分辨率提高 → 满足要求 ✅

过零法测频精度:
  2MSPS, 10kHz: 200 samples/cycle → 10kHz/200 = 50Hz 精度 ✅
  2MSPS, 500kHz: 4 samples/cycle → 500kHz/4 = 125kHz ✗
  
  → 解决方案：对500kHz信号，用多周期平均
  256μs内2.5个周期 → 跨100个周期(50ms)累积过零 → 500Hz精度 ✅
```

### 6.2 2秒时间预算

```
2秒内任务:
├─ ADC稳定采样          0.5ms   (DMA启动后瞬时稳定)
├─ 频率粗测(过零法)      10ms    (100个周期积累)
├─ 频谱分析(FFT)        0.256ms (单帧512点)
├─ 波形捕获+触发        0.5ms   (单帧)
├─ 多次测量平均          100ms   (提高精度)
├─ TJC屏更新            50ms    (UART 115200, 异步)
└─ 总计                 ~162ms  ← 远小于2秒 ✅
```

## 七、PGA 带宽问题的两种解决方案

### 方案A：AD620 G=1 直通 + ADC直接采样（推荐）

```
AD620 G=1, BW≈1MHz → 500kHz信号可通过
50mVpp → 50mVpp(无放大) → 仅用62个ADC LSB
靠512点过采样 + 数字平均提高有效分辨率
优点：不需要换硬件，AD620已有
缺点：50mVpp小信号边缘情况需验证
```

### 方案B：换宽带PGA

```
AD8250: BW=12MHz@G=10, 引脚兼容SOIC
THS7530: BW=300MHz, VGA
优点：信号质量好，动态范围大
缺点：芯片不一定有库存，焊接风险
```

> **建议**：先用方案A验证，50mVpp小信号若精度不够，紧急启用方案B。

## 十一、设计报告结构（20分，提前准备）

1. **方案论证（3分）**
   - 平台选择：MCXN947 vs MSPM0G3519 vs FPGA
   - 采样方案：实时采样 vs 等效采样
   - 频谱方案：FFT vs Goertzel vs 扫频超外差
   - 滤波方案：模拟 vs 数字 vs 混合

2. **理论分析与计算（5分）**
   - ADC采样率与Nyquist约束
   - FFT频率分辨率与插值精度
   - 真有效值的数学定义与数字化实现
